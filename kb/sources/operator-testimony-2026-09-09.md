## Why this is its own source

Everything else at L0 here is an archive — a message export, a git history, a
scrape. This is the subject speaking, now, about the past. It is the only source
in the repository that can answer a question the archives leave open, and the
only one whose reliability depends on memory rather than on capture.

`testimony = true`, so every datum citing it must carry `attributed_to`. That is
not scepticism about this particular speaker; it is the same rule applied to the
prior wiki's export, and it exists so a later reader can tell *the operator said
X* from *X*.

## What the prior wiki established about this source class

`wiki/meta/testimony-veracity` scored sixteen of the operator's own first-person
claims against independent records
([`dat:0044`](../data/0044-old-wiki-testimony-ledger.md)). At n=10 its finding is
a suggestion rather than a measurement, and the suggestion is uncomfortable:
claims he stated as `certain` held up 0.25 of the time, while claims he `hedged`
held up 0.75.

That is a reason to attribute rather than to discount. Testimony that explains
previously incoherent evidence is doing something a confident assertion about a
bare fact is not — see
[`dat:0058`](../data/0058-graduation-september-2009-then-audit-and-certification.md),
where the account offered resolves four dated artefacts that had no consistent
reading without it.
