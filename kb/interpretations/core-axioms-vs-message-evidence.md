## The thesis

The wiki's four core axioms — *not exceptional = worthless; not vigilant =
annihilated; love that doesn't cost everything isn't real; time = countdown* —
do load-bearing psychological work in the dossiers: they explain everything and
are evidenced by nothing in the held record. The one attempt to test them against
behavior, the ledger's t011, found no lexical corroboration in 106,629 outbound
messages — and on every explicit urgency construction but one, he writes *less*
than his 503 controls
([`dat:0044`](../data/0044-old-wiki-testimony-ledger.md)). The observable
direction runs *against* the "time = countdown" axiom, not merely absent from it.

## What t011 actually did

Four claimed unconscious axioms, tested lexically against 106,629 of his sent
messages with 110,944 inbound messages from 503 handles as a within-medium
control. On every explicit urgency construction but one he writes less than the
controls. The ledger's own reading: this does not falsify the axioms, because
SMS is a near-zero-introspection medium for everyone in it — it establishes
that the message corpus cannot corroborate them.

That reading is doing two jobs at once. It is methodologically honest: the
corpus is a record of attention, not interior state, and failure to corroborate
is not falsification — the same jurisdiction
[`dat:0890`](../data/0890-big-five-corpus-audit-and-self-typing.md) carries for
its silent psychometric facets. And it is structurally convenient: if the only
test that can reach a claim is defined so that its null result says nothing,
the claim is unfalsifiable inside this system. The ledger's own discipline is
to score `unfalsifiable` as zero, never negative — but the axioms keep doing
explanatory work while carrying a score of "cannot be checked."

## How the ingest bears on it

The axioms' provenance is the commissioned-instrument base. The Context Core
page's typological and axiom layers rest on the AI-dossier material it labels
as such ([`dat:1032`](../data/1032-context-core-staleness-audit-2026-08-16.md));
the function scores behind the cognitive profile are AI-inferred testimony with
the commissioned-self connection explicit, not measured facts
([`dat:0756`](../data/0756-intp-profile-function-scores-testimony.md)). The
source files the axioms presumably came from — CONTEXT_CORE_EXPANDED.md, the
dox-scan profile documents — are not held in this repository. So the shape is:
commissioned → reified by repetition → load-bearing in synthesis → untestable
in corpus. That is not evidence the axioms are false. It is evidence the
architecture has no way to know, and no route by which it could find out —
which is exactly the condition the wiki's own governance rule was written for:
"documented counts, timelines, and primary records override generated metaphor"
([`dat:1032`](../data/1032-context-core-staleness-audit-2026-08-16.md)). The
axioms may be the generated metaphor the rule was aimed at.

## The contradiction inside the dossier

The axioms are described as *unconscious*. An unconscious axiom is predicted to
be invisible in explicit utterance — which means the t011 null result is what
the theory predicts, and the theory is also what makes the null result
meaningless. The interesting part is that the one observable that *does* reach
an axiom's content goes the wrong way: "time = countdown" predicts urgency
language; the behavioral record shows *less* urgency than controls. Absence
would be neutral. Reversal is not.

## Open questions

- Is there any held medium with real introspection — journals, long-form
  writing, the planned video-essay scripts — where axiom-shaped language
  appears? No latent-framing test has been run; the explicit-lexicon test may be
  the wrong instrument.
- What did the axioms' original dossier source actually claim? The unheld
  CONTEXT_CORE_EXPANDED.md is the load-bearing missing file for this entire
  question.
