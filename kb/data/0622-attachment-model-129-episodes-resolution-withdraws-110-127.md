## Why this changes the reading

Before this resolution the strongest version of the evidence was 127
declarations with 110 re-engagements — 87%, a strong but ordinary pattern
a skeptic could read as weak resolve. The independent recount moved it to
129 declarations with **100% resumption and a 36-second median gap**, which
is not a pattern of failed exits at all; it is a pattern in which declared
exits *terminate nothing*, exactly what a no-counter-rule architecture
predicts. The page is explicit that this is the strongest quantitative
support the architecture has ever had, and it withdrew the weaker figure
rather than letting both stand. Cross-reference
[`dat:0449`](0449-group-chat-closure-revised-arithmetic.md) for the sibling
self-correction on the closure arithmetic — this node is the distinct
exit-episode finding and is not a duplicate.

## What it does not confirm

The episode definition (severance lexicon, 24-hour collapsing rule) is the
page's; 258 messages → 129 episodes is its arithmetic. The merged 95,067-
row corpus is not held here, so neither the 129 nor the 36-second median
is re-derivable in this repository. The severance lexicon itself is also
partial by the page's own admission — *\"blocking declarations\"* as a
category overlaps with the block-unblock loop's channel operations, and the
page does not say how double-counted instances were handled.
