## What this is evidence of

The index is infrastructure, not testimony. Its value is the declared
design rule (fix the source page, never the timeline; the Annie record
is read, the master timeline is extracted) and the honest 'In progress'
marker. The stale stats are exactly the class of drift the wiki's own
governance warns about: a summary that was written once and not
regenerated with the thing it summarizes.

## What it is not

A source for any event date. Every dated claim in the event list is a
pointer; the datums live on the event pages, several already covered in
this worker's nodes (dat:0357–0361) and others' (dat:0492/0493).
