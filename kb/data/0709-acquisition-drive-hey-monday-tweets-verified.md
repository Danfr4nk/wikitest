## What this does for the page

The page added this section 2026-09-04 precisely because the ATM-card
episode — its only other illustration — 'has no date, no amount, no
duration and no corroboration anywhere in the message corpus.' The
tweet-sourced instance supplies all four: dated to the day, a named band,
a named small room in Orlando, a mid-holiday Pennsylvania-to-Florida
flight. It does not measure the drive's amplitude — the page is explicit
that one concert is not a rate — but it does date the mechanism to age
twenty in a first-party contemporaneous record, which is what the page
claims for it and nothing more.
